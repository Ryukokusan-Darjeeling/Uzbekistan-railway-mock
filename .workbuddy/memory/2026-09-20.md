## 地图方案最终定版：Leaflet + OSM 现代瓦片（可缩放）
- 用户三次调整地图诉求：手绘轮廓太丑 → 要真实历史古地图 → 但历史地图方案（David Rumsey IIIF、OpenHistoricalMap 矢量瓦片）在验证时反复卡住（浏览器自动化等 networkidle 永不返回、OHM 被 Cloudflare 拦 curl、filterByDate 插件是 CJS 无法直接 ESM import）。
- 用户最终拍板："回退，实在不行找现代地图资源，类似之前版本，能缩放就行"。
- 最终方案：**Leaflet + OpenStreetMap 现代栅格瓦片**（与 1.0 完全一致的技术栈，稳定、可缩放、不卡）。
  - index.html：`https://unpkg.com/leaflet@1.9.4/dist/leaflet.css` + `leaflet.js`
  - map.js：`L.map` + `L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png')`，商路节点用 `L.divIcon`（无 emoji），连线用 `L.polyline`（陆路主线 #8B3A1A 实线、避税支线 #43B3AE 虚线）
  - 默认 center [42,112] zoom 4，首次 fitBounds 到商路范围
- 教训：不要用 agent-browser 等浏览器自动化去等矢量瓦片（networkidle 永不返回）；静态验证（curl CDN/瓦片 200 + node --check）已足够。

## UI 收尾：地图修复 + 智能体决策过程可视化
- **地图不显示**：根因是 CSS 高度塌陷——`#cku2Map` 自身被 Leaflet 初始化为 `.leaflet-container`，但 CSS 用了后代选择器 `.cku2-map .leaflet-container`，高度规则没命中容器自身。修复：`.cku2-map` 直接设 `height:520px` + `.cku2-map.leaflet-container`，并 `::before {display:none}` 去掉装饰框。
- **连线不经过节点**：divIcon marker 的 `transform:translate(-50%,-50%)` 导致图标圆心与连线端点错位。修复：节点改用 `L.circleMarker`（锚点精确在经纬度），城市名用 `L.tooltip permanent:true`。
- **智能体决策可视化**：orchestrator 新增 `agent_start`/`agent_done` 细粒度上报（含 role/name/post/city/decision），app.js 渲染「决策流时间线」——每个 agent 决策时先显示"正在斟酌利弊…"（齿轮动画），完成后替换为具体决策（加税/克扣/贿赂/勾结/观望）。容器 `#cku2AgentStream`，回合结束自动隐藏。替代原先单一加载圆圈。
